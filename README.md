# Сайт по бронированию столиков
## Описание проекта:
Это веб-приложение для бронирования столиков в ресторанах. Пользователи могут просматривать список ресторанов, выбирать свободные столики и создавать бронирования. Владельцы ресторанов и менеджеры 
могут управлять своими ресторанами, столами и бронированиями.
## Основные функции ##
1. Просмотр списка ресторанов и их информации
2. Просмотр деталей ресторана, включая план рассадки
3. Создание, редактирование и удаление ресторанов (для владельцев)
4. Управление столами: добавление, редактирование, удаление
5. Просмотр и управление бронированиями
6. Создание бронирования с выбором свободных столиков
7. Уведомления владельцам И менеджерам о новых бронированиях в их ресторанах
8. Ограничение доступа по ролям (администратор, менеджер, пользователь)
## Технологии ##
1. Django (Python) — backend
2. Django ORM — модели данных
3. Django Class-Based Views — обработка страниц
4. Bootstrap — фронтенд
5. Bootstrap Icons — иконки
6. PostgreSQL — база данных
7. Django Permissions и Groups — управление правами доступа
8. phonenumber_field — валидация телефонных номеров
9. Docker Compose — оркестрация контейнеров, автоматизация развертывания и обмена данными между сервисами 
10. GitHub Actions — автоматизация CI/CD, обмен кодом и деплой через интеграцию с GitHub

## Установка: ##

1. Клонируйте проект в свой репозиторий по ссылке:
```
git clone github.com/DashulyaE/online_store_django
```
## Настройка удаленного сервера ##
- Откройте терминал и выполните команду для обновления списка пакетов:
```
sudo apt update
```
 - Затем выполните команду для обновления всех установленных пакетов до их последних версий:
```
sudo apt upgrade
```
4. Установка Docker 
Чтобы установить Docker, воспользуйтесь инструкцией по установке с официального сайта: https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository.
5. Настройте файрвол

### Шаги для запуска workflow и деплоя приложения ###
1. В вашей репозитории на github перейдите в Settings > Secrets.
2. Добавьте секреты:
- SSH_KEY — приватный SSH-ключ для доступа к серверу
- SERVER_IP - IP-адрес сервера
- SSH_USER — пользователь для SSH
- DEPLOY_DIR — путь к директории проекта на сервере
- остальные секреты добавлять в соответствии с файлом .env.example
3. Не забудьте сгенерировать ssh ключ (публичный и приватный) для автоматических сервисов
4. Адрес сервера с развернутым приложением
```
158.160.172.235
```
4. Запуск workflow
- После пуша изменений GitHub автоматически запустит workflow.
### Запуск на локальном сервере ###
В командной строке терминала введите команду
```
docker-compose up --build
```
Она запустит контейнеры.
### Запуск на удаленном сервере ###
1. Подключитесь к серверу через команду в командной строке
```
ssh <пользователь>@IP-адрес сервера
```
2. Скопируйте файлы проекта на сервер (через Git).
3. Запустите приложение командой
```
docker-compose up --build
```
