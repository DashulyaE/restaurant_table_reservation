# Сайт по бронированию столиков
## Описание проекта:
Это веб-приложение для бронирования столиков в ресторанах. Пользователи могут просматривать список ресторанов, выбирать свободные столики и создавать бронирования. Владельцы ресторанов и менеджеры 
могут управлять своими ресторанами, столами и бронированиями.
## Основные функции ##
1. Просмотр списка ресторанов и их информации
2. Просмотр деталей ресторана, включая план рассадки
3. Создание, редактирование и удаление ресторанов (для владельцев)
4. Управление столами: добавление, редактирование, удаление
5. Просмотр и управление бронированиями
6. Создание бронирования с выбором свободных столиков
7. Уведомления владельцам о новых бронированиях
8. Ограничение доступа по ролям (администратор, менеджер, пользователь)
## Технологии ##
1. Django (Python) — backend
2. Django ORM — модели данных
3. Django Class-Based Views — обработка страниц
4. Bootstrap — фронтенд
5. Bootstrap Icons — иконки
6. PostgreSQL — база данных
7. Django Permissions и Groups — управление правами доступа
8. phonenumber_field
— валидация телефонных номеров
